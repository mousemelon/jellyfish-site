# Medusae

Статический сайт о медузах: биолюминесценция, строение, жизненный цикл и виды.

Live: https://mousemelon.github.io/jellyfish-site/

## Что внутри

- Адаптивный one-page на чистых HTML/CSS/JS.
- Локальные оптимизированные WebP-изображения.
- Open Graph/Twitter metadata для шаринга.
- Reduced-motion fallback для анимаций.

## Локальный запуск

Откройте `index.html` в браузере или поднимите любой статический сервер:

```bash
python3 -m http.server 8080
```

## Деплой

Проект рассчитан на GitHub Pages из корня ветки `main`.

После merge в `main` GitHub Pages публикует сайт автоматически.
